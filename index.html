ABOUT US

코드로 성장을 설계하는
1인 IT 기업, Code&Rise

코드앤라이즈는 대표 이재흔이 직접 기획부터 설계, 개발, 운영까지 전 과정을 책임지는 프리랜서 IT 스튜디오입니다. 대기업 그룹웨어 모듈 개발 및 운영, 각종 레거시 시스템 API 연동 경험을 바탕으로 안정적이고 실무에 강한 결과물을 만듭니다.

중간 단계 없이 대표와 직접 소통하며 빠른 의사결정과 유연한 대응이 가능한 것이 코드앤라이즈의 가장 큰 강점입니다. Web, App, ERP, DB, Server, Cloud, System Integration까지 — 하나의 창구에서 끝까지 책임집니다.
